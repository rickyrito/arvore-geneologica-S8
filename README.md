# Árvore genealógica — Família Rito do Soito

Página: https://rickyrito.github.io/arvore-geneologica-s8/

Dados transcritos dos assentos paroquiais do Soito (Sabugal) publicados no blogue [Saber Soito](https://soitoribacoa.blogspot.com/2018/02/familia-rito.html).

- `index.html` + `dados.js` — explorador da árvore (706 pessoas visíveis; pessoas possivelmente vivas ocultadas)
- `familia_rito_soito.ged` — GEDCOM 5.5.1 completo, para importar em Gramps, MyHeritage ou MacFamilyTree
- `familia_rito_soito.csv` — uma linha por pessoa
